## English

### SmartSolutionsLab

**Professional software, built with architectural discipline.**
We build distributed .NET systems with React frontends: domain-driven, test-driven, and with every architectural decision written down.

#### Projects

| | Project | Description | Stack |
|---|---|---|---|
| 🎥 | [**smart-sentinel-eye**](https://github.com/smartsolutionslab/smart-sentinel-eye) | Camera and video management for industrial production in 24/7 operation, designed for 250 cameras. Live video over WebRTC, event overlays in ≤ 800 ms. | .NET Aspire · WebRTC · React · k3s |
| 🍳 | [**yumney**](https://github.com/smartsolutionslab/yumney) | A PWA that extracts recipes from any URL using an LLM, generates shopping lists and guides you through cooking step by step. | .NET · React · LLM |
| 🏢 | [**roomy**](https://github.com/smartsolutionslab/roomy) | Office management. | .NET |
| 🧱 | [**software-fabric**](https://github.com/smartsolutionslab/software-fabric) | A template for starting new solutions on this architecture. | .NET |

#### How we build

- **Domain-driven design** with bounded contexts, hand-written value objects and strongly typed IDs
- **Architecture decision records** for every significant decision
- **Spec → plan → tasks → tests → code.** New behaviour starts with a failing test.
- **Enforced architecture rules** through NetArchTest, analyzers and coverage gates in CI
- **AI-assisted development** with clear phase gates and human review

`C#` `.NET` `.NET Aspire` `ASP.NET Core` `PostgreSQL` `RabbitMQ` `Wolverine` `React` `TypeScript` `Tailwind` `Keycloak` `WebRTC` `OpenTelemetry` `Docker` `Kubernetes`
